# 👨‍💻 김예환 (Kim Yehwan)

> **"시도와 실패를 두려워하지 않는 도전 정신"**  
> ﻿개발자로의 직무 전환을 결심하고 C언어를 시작으로 JAVA기반 백엔드 기술을 체계적으로 익혔습니다. <br>
> 국비 지원 교육 과정을 수강하면서 5인 팀 프로젝트로 ‘야구 티켓 예매 플랫폼’ 및 ‘원데이 클래스 예약 플랫폼’을 구축했습니다. <br>
> 초반에는 요청과 응답, DB데이터가 화면에 표시되는 데이터 흐름이 익숙하지 않았으나, 실행 흐름을 단계별로 분석하고 학습하여 이해도를 높였습니다. 직무 전환 과정에서 쌓은 실행력과 반복 학습 습관을 바탕으로, 맡은 기능의 구조를 이해하고 끝까지 완성할 수 있는 개발자로 성장하겠습니다.

<br>

## 1. BallPick
> 야구 예매 사이트
> - 소개 : 좌석 선택부터 외부 결제 API 연동까지, 중복 예매 방지와 결제 데이터 안정성에 집중한 야구 티켓 예매 플랫폼
> - 개발 기간 : 2026.06.02 ~ 07.10
> - 핵심 역할 : ﻿Servlet/JSP 기반 개발환경 구축 및 프로젝트 초기 세팅, 예매 데이터 처리를 위한 Database 설계 및 구축, 팀 페이지 및 결제 페이지 UI개발
> - 기술 스택 : ﻿Java 17, HTML5/CSS, JavaScript, Servlet/JSP
> - 프로젝트 소개 : https://app.notion.com/p/BallPick-dc5cb69d803282e5855901ec352e7646?source=copy_link

## 2. OneClass
> 원데이 클래스 예약 사이트
> - 소개 : Spring Boot기반의 MVC 패턴을 사용하여 생산성을 높인 원데이 클래스 예약 플랫폼
> - 개발 기간 : 2026.07.11 ~ 08.28
> - 핵심 역할 : ﻿Spring Boot 기반 개발환경 및 프로젝트 아키텍처 초기 구축, Oracle DB 데이터 모델링 및 스키마 설계(ERD 작성), Kakao Map API 연동을 통한 위치 기반 클래스 공방 조회 기능 구현, PG사 API연동을 통한 온라인 예약·결제 시스템 구축, Thymeleaf 기반 클래스 상세 조회 페이지 및 사용자 UI 구현
> - 기술 스택 : ﻿Java 17, Spring Boot, MyBatis, HTML5/CSS, Thymeleaf
> - 프로젝트 소개 : https://app.notion.com/p/OneClass-3c5cb69d803280669e2bf8ce9da1e737?source=copy_link
